# The shared guestbook + plans calendar backend

**Status (2026-11-17):** the Google Sheet **chawal backend** and its Apps Script project are already set up on the group's Google account. Everything below is for reference, or for setting it up again from scratch.

Until the site's `backend:` URL is set in [`js/data.js`](../js/data.js), the guestbook and calendar run in **demo mode**, which saves on your own device only.

## Where things live (in the Google Sheet)
| tab | what it is |
|---|---|
| `members` | everyone's **email** (name in column A, email in column B). Fill these in; anyone left blank just won't get emails. |
| `settings` | `passcode` is the group password the site asks for (generated by `setup`, so share it in the group chat). `site_url` is the live scrapbook link used in emails. |
| `notes` | guestbook entries (delete a row to remove a note) |
| `plans` | calendar plans, RSVPs and reminder status |

## From scratch
1. Go to [sheets.new](https://sheets.new) and open **Extensions → Apps Script**.
2. Paste in [`backend/Code.gs`](Code.gs), then press **Save**.
3. In **Project Settings**, make sure **Enable Chrome V8 runtime** is ticked and the time zone is India.
4. Run `setup`, then click **Review permissions → your account → Advanced → Go to (unsafe) → Allow**. The warning only appears because it's your own unreviewed script.
5. Click **Deploy → New deployment → Web app**, set **Execute as: Me** and **Who has access: Anyone**, then **Deploy** and copy the `/exec` URL.
6. Paste that URL into `backend:` in `js/data.js`.

## What it does automatically
| When | What happens |
|---|---|
| someone pins a plan with **email** ticked | everyone picked gets a scrapbook-style email |
| **google calendar invite** ticked | the plan lands in their Google Calendar |
| **whatsapp** ticked | the poster gets a one-tap button that opens WhatsApp with the message ready |
| the day before, and the morning of | reminder email to everyone who hasn't said "can't" |
| someone RSVPs | the person who made the plan gets an email |
| a plan is cancelled | optional "it's off" email to everyone |

## Changing the code later
Go to **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. The URL stays the same.
Gmail allows about 100 email recipients a day on a normal account.

## Why WhatsApp isn't fully automatic
Automatic WhatsApp messages need the paid WhatsApp Business API. A Telegram group + bot could be fully automatic and free, if you ever want that.
