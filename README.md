# chawal

A page-flip digital scrapbook for **chawal**: Muhsin, Pavitra, Hatim, Hamza & Tanya.

It's a static site (no build step): open `index.html`, or deploy the folder as-is.

- `js/data.js`: member blurbs, the VHS tapes (edits), photo captions, and the backend link
- `js/book.js`: the page-flip book engine
- `backend/Code.gs`: the Google Apps Script that powers the shared plans calendar + guestbook (see `backend/SETUP.md`)
- Everyone's emails for plan notifications go in the **members** tab of the "chawal backend" Google Sheet, not in this repo.
